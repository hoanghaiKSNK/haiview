# Changelog

All notable changes to HaiView. Versions follow [Semantic Versioning](https://semver.org).

## [0.3.0] - 2026-11-11

First public release.

### Added
- macOS app (Apple silicon and Intel) and Windows app (x64 and ARM64).
- Built-in layouts: 1, 2 side by side, 2 stacked, 3 side by side, 2 top 1 bottom, 1 top 2 bottom, 1 large + 2 small, grids.
- Custom layouts: drag dividers to resize, split or remove cells, save layouts by name.
- Flip the whole group or a single selected cell; type a page number to jump.
- Page list with thumbnails: click to jump, or drop a page into a cell.
- Open PowerPoint files directly (converted with the PowerPoint installed on the computer).
- Present on a second screen, black screen, page numbers, keyboard and clicker support.
- English and Vietnamese interface (follows the system language, can be changed in the app).
