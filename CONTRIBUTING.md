# Contributing to HaiView

Thanks for helping. HaiView is small on purpose: a fast way to show several pages on one screen.

- **Bugs:** open an issue with your OS version, the file type (PDF or PowerPoint) and the steps to reproduce. A screenshot helps a lot.
- **Ideas:** open an issue and describe the teaching situation behind it. Real use cases decide the roadmap.
- **Code:** fork, create a branch, keep the change focused, and open a pull request. Please build both apps if you touch shared behaviour, and keep the Mac and Windows versions in step.
- **Translations:** all interface text lives in `L("English", "Tiếng Việt")` calls (`macos/Sources`, `windows/HaiView`). Adding a language means extending that helper.

Please don't commit real patient data, real exam papers or other private material in examples or screenshots.
